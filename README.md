# journey_english

Веб-приложение для изучения английского языка на Django.

## Запуск проекта на Windows

### 1. Установить Git

Если Git ещё не установлен, скачайте его с официального сайта:

https://git-scm.com/download/win

Проверить установку:

```cmd
git --version
```

---

### 2. Клонировать ветку `dev`

Откройте **CMD** или **PowerShell** и перейдите в папку, где хотите разместить проект:

```cmd
cd "C:\Users\ВашеИмя\Documents"
```

Клонируйте проект сразу из ветки `dev`:

```cmd
git clone -b dev https://github.com/BubaLisa/journey_english.git
```

Перейдите в папку проекта:

```cmd
cd journey_english
```

Проверить текущую ветку:

```cmd
git branch
```

Должно быть:

```text
* dev
```

---

### 3. Установить `uv`

`uv` используется для установки зависимостей и управления виртуальным окружением проекта.

В CMD выполните:

```cmd
winget install --id=astral-sh.uv -e
```

После установки закройте CMD и откройте его заново.

Проверьте установку:

```cmd
uv --version
```

---

### 4. Установить зависимости

Убедитесь, что вы находитесь в папке проекта:

```cmd
cd "C:\Users\ВашеИмя\Documents\journey_english"
```

Установите зависимости:

```cmd
uv sync
```

Команда автоматически создаст виртуальное окружение `.venv` и установит зависимости проекта.

---

### 5. Создать файл `.env`

В корневой папке проекта создайте файл:

```text
.env
```

Структура должна выглядеть примерно так:

```text
journey_english/
├── .env
├── education/
├── manage.py
├── pyproject.toml
├── uv.lock
└── README.md
```

В `.env` добавьте секретный ключ:

```env
DJANGO_SECRET_KEY="ваш-секретный-ключ"
```

**Ключ обязательно рекомендуется заключить в кавычки**, особенно если в нём присутствуют специальные символы.

Сгенерировать новый ключ можно командой:

```cmd
uv run python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

Полученный ключ вставьте в `.env`:

```env
DJANGO_SECRET_KEY="полученный-ключ"
```

---

### 6. Выполнить миграции

Создайте/обновите структуру базы данных:

```cmd
uv run python manage.py migrate
```

Если команда выполнилась без ошибок, база данных готова к запуску.

---

### 7. Запустить сервер

Выполните:

```cmd
uv run python manage.py runserver
```

При успешном запуске появится сообщение:

```text
Starting development server at http://127.0.0.1:8000/
```

---

### 8. Открыть приложение

Откройте браузер и перейдите по адресу:

http://127.0.0.1:8000/

Также можно использовать:

http://localhost:8000/

---

## Остановка сервера

Для остановки Django-сервера нажмите:

```text
Ctrl + C
```

---

## Обновление проекта

Если проект уже клонирован и нужно получить последние изменения из ветки `dev`:

```cmd
git pull origin dev
```

После получения изменений обновите зависимости:

```cmd
uv sync
```

Если изменялась структура базы данных:

```cmd
uv run python manage.py migrate
```

После этого запустите сервер:

```cmd
uv run python manage.py runserver
```
